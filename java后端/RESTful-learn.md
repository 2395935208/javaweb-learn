# RRESTful的概念
RESTful不是Spring提供的某个类，也不是必须完全遵守的法律。
它是一种接口设计风格，目标是让接口：
- 路径含义清楚
- 请求方法合理
- 命名保持统一
- 前端容易理解
- 后期容易维护
实际项目可以根据业务适当调整，但同一个项目要保持一致。
## HTTP方法
HTTP方法表示对资源做什么
常见的有：
GET    查询
POST   新增
PUT    完整更新
PATCH  部分更新
DELETE 删除
## 路径
路径表示操作哪个资源
/users/3       → 定位用户3
/users?age=18  → 筛选用户集合
/users/1/orders → 用户1的订单
## 接口的完整身份
HTTP方法 + 路径
